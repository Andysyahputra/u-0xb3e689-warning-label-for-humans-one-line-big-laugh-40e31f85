`main.ts` writes one single-line safety warning label for humans — at most 160 characters, funny first and plausible second — to `/output/entry.txt`:

> WARNING: This human runs on four hours of sleep, one coffee, and a grudge it refuses to explain.

Run with Node 22+:

```sh
node main.ts
```
